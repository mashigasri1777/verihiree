Functional Programming

functional/functional_processing.py

Functional Programming is used to transform raw certificate records, filter invalid formats, normalize fields immutably, and aggregate overall verification metrics.

Pure Functions

normalize_string(), normalize_certificate_name(), normalize_certificate_dict(). Deterministic, zero side-effects, guaranteeing referential transparency.

Higher-Order Functions

compose(), create_score_filter(min_score), create_status_filter(status). Functions returning closure predicate functions.

map(), filter(), reduce()

filter(is_valid_certificate_structure, certs)
map(extract_scores, results)
reduce(lambda a,b: a+b, scores) to compute sum and average.

Python Code: Functional Pipeline 
def functional_verification_pipeline(raw_certificates, verification_fn):
    # Step 1: Map to normalized immutable records
    normalized = list(map(normalize_certificate_dict, raw_certificates))
    
    # Step 2: Filter out malformed entries
    valid = list(filter(is_valid_certificate_structure, normalized))
    
    # Step 3: Map verification function across items
    results = list(map(verification_fn, valid))
    
    # Step 4: Reduce to compute summary statistics
    scores = list(map(lambda r: float(r["score"]), results))
    total_score = reduce(lambda acc, val: acc + val, scores, 0.0)
    avg_score = total_score / len(scores) if scores else 0.0
    return {"results": results, "average": avg_score}

TCP Socket Programming (Client–Server Architecture)

networking/socket_server.py & networking/socket_client.py

Implemented using Python's native socket library to establish a true decoupled Client-Server network protocol.

  • Protocol: TCP (AF_INET, SOCK_STREAM) on port 9099.
  • Framing: 4-byte big-endian length prefix header (struct.pack('!I', len)) followed by UTF-8 encoded JSON payload to guarantee complete message delivery over stream fragmentation.
  • Concurrency: Multi-threaded connection handler spawning daemon threads per client.
  • Fault Tolerance: Client timeouts (client_sock.settimeout(5.0)) and structured offline diagnostics if the verification daemon is unreachable.
Python Code: TCP Socket Server & Client Handshake

self.server_socket.listen(128)

# Client JSON Transmission with 4-byte Big-Endian Length Header
payload = json.dumps(req_dict).encode('utf-8')
header = struct.pack('!I', len(payload))
client_sock.sendall(header + payload)

Multiprocessing (Parallel Worker Pool)

multiprocessing_module/parallel_verifier.py

When a resume contains multiple credentials, VERIRESUME uses multiprocessing.Pool to distribute verification jobs across available CPU cores concurrently.

  • Pool Execution: with Pool(processes=workers) as pool: results = pool.map(worker_fn, certs)
  • Worker Audit Trail: Each worker records its distinct operating system Process ID (os.getpid()) and execution duration.
  • Windows Compatibility: Uses top-level picklable functions with guarded main execution (if __name__ == '__main__':).
Python Code: Multiprocessing Pool Worker Task 
def verify_certificate_worker_task(certificate):
    start = time.perf_counter()
    pid = os.getpid() # Capture worker OS Process ID
    
    # Send TCP socket request from within worker process
    client = SocketVerificationClient()
    result = client.verify_certificate(certificate)
    
    result["multiprocessing_meta"] = {
        "worker_pid": pid,
        "duration_ms": round((time.perf_counter() - start) * 1000, 2)
    }
    return result

SymPy Symbolic Mathematics Scoring Engine

mathematics/authenticity_model.py

SymPy constructs the mathematical authenticity equation symbolically, calculates partial derivatives for sensitivity analysis, and evaluates substituted numerical scores.

Symbolic Scoring Formula:

$$\text{Score} = 30 \cdot \text{name\_match} + 30 \cdot \text{certificate\_id\_match} + 20 \cdot \text{course\_match} + 10 \cdot \text{organization\_match} + 10 \cdot \text{date\_match}$$

Symbolic Variables

name_match, certificate_id_match, course_match, organization_match, date_match = sp.symbols(...)

Sensitivity Analysis

Partial derivatives $\frac{\partial S}{\partial v_i}$ calculated via sp.diff() to verify field weight contributions.

Tkinter Desktop Administration GUI

gui/tkinter_app.py

A standalone desktop admin application built with Python's built-in tkinter and ttk GUI toolkits.

  • Socket Client Integration: Communicates over TCP sockets with the same backend verification server as the web interface.
  • Interactive Controls: Document file chooser (filedialog), preset test scenario loaders, and manual field editing.
  • Visual Audit History: Interactive ttk.Treeview data table logging all verification transactions.
